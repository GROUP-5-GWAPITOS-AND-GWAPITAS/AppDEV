## Step 4: Commit the Changes

1. Scroll to the bottom of the page.
2. Under **"Commit changes"**:
   - **Commit message:** `Add project README`
   - Leave the extended description blank.
3. Choose: **"Commit directly to the `main` branch"**
4. Click the green **"Commit changes"** button.

---

## Step 5: Watch for the Ruleset

Since you set up a ruleset on `main`, GitHub **might block the direct commit**.

**Two possible outcomes:**

- ✅ **It commits successfully** → README is updated! Move on to Step 8.
- ❌ **Error: "Changes must be made through a pull request"** → Your ruleset is working. We'll do it via a branch + PR instead.
